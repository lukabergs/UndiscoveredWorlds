Controlled height-reduction probe

Stationary single plate · uniform imported plateau · ordinary erosion off. Glacial strength: green = 0; yellow = 0.000001; orange = 0.35. Solid = 1 Myr per update; dashed = 0.1 Myr per update. Five updates in each case; seed recorded in the probe file.

The near-zero setting already activates almost the full glacial height cap. Similar per-update loss over different geological durations reveals missing timestep scaling. These probes diagnose current heuristics; they do not calibrate physical erosion rates.
