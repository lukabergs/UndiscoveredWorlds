## 2. Rules for this roadmap

- One phase per session (memory "Phase sessions"); every step records its duration (ledger field, the Duration column below) and gets a ledger entry: pipeline steps in `runs/ledger/erosion.jsonl` (tectonics engine steps in `tectonics.jsonl`), sandbox steps as one entry per sandbox phase in `erosion.jsonl` with `"module": "erosion"` (the ledger tool accepts only the file's module), `"phase": "terrain sandbox ..."` and the commit range.
- Python runs from Git Bash as from PowerShell: `uv.exe` is on Git Bash's `PATH` (the `~/bin/uv.cmd` wrapper only forwards to it), so `uv run python scripts/sandbox/...` works in either shell (checked 2026-10-13). PowerShell is needed only for the `.cmd` wrappers (`msvc-env.cmd`, `cmake-vs.cmd`, `ninja-vs.cmd`) of a C++ build. In Git Bash, write scripts with the Write tool rather than heredocs (apostrophes and backslashes break them), never `cat > file` without input (it waits on stdin), and never name a scratch script after a standard-library module (`inspect.py` broke numpy's import).
- Sandbox steps are judged by the user's look (pages under `out/scratch/sandbox/<label>`, Earth atlas beside); no parity runs, no tests unless a bug persists. Pipeline steps keep the repository's checks (`step_check.py` at the minimal configuration for parity; one judging run where the change acts).
- The reviewer runs on Opus 5.5 (`model: opus`) while Fable is off; a `design` agent likewise. Reviews follow each behaviour step of the pipeline (T2, T3, T4); sandbox steps are reviewed by the user's look.
- **user** marks a decision only the user takes; the orchestrator continues with independent work meanwhile.

- *Ridges and speed:* no ridge object (a ridge is where the remap leaves coverage below 1; new basalt at age 0, `tectonic_columns.cpp:591-617`); plates translate without rotating (`lithosphere.cpp:2404`), so the relative velocity is uniform along a boundary and nothing segments a ridge but the raster; `BoundaryType::Transform` is a diagnostic label (shear at least divergence). Speeds come from a force balance (`tectonic_dynamics.hpp:12-17`, drags 5e14 basal, 1e21/8e21/5e20 boundary) driven by a 4 cm/yr mantle flow plus slab pull: run 78's mean 0.73 cm/yr, max 1.67 (Earth's mean about 5). No unit error found: the slow ageing is the drags' (inference, not quantified).
- *Subduction:* the older ocean-ocean side descends (`tectonic_margins.cpp:66-75`); arc basalt from the overlap sink; trench load from closing speed and slab age (`:88-89`); the slab age, closing speed and descending side are available per face (`tectonic_dynamics.hpp:24-38`). - **The sandbox's time scale (2026-10-14, the user's question: is the erosion too strong, are the lowstands 10 times too long?).** The fluvial law is E = K Q^m S with E in m/Myr and Q in km^3/yr (`stream_power.hpp`); in the usual drainage-area form E = K_A A^0.5 S (A in m^2, E in m/yr), K_A = 3.16e-11 K r^0.5 with r the runoff in m/yr: K 3000 at r 0.15 to 1 m/yr gives K_A about 4e-8 to 1e-7 per year, the low end of the range usually quoted for bedrock rivers (about 1e-7 to 1e-4 per year for n = 1; from memory, not checked against a source). B's 20 Myr of physics lowered its land by about 350 m, about 17 m/Myr on average (Earth's continents about 10 to 50 m/Myr, active ranges hundreds).
