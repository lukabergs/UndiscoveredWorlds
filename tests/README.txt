Explain the test architecture and their goals.

Review (2026-09-03):
CMake registers 14 headless C++ test executables. core/ checks spherical grids, conservation and remapping; pipeline/ checks stage dependencies/order; io/ checks reference bundles, TIFF contracts, and map selection; simulations/climate/ checks energy, moisture transport, atmosphere/ocean dynamics, classification and weather replay. simulations/geology/plate_tectonics/ retains the native engine, surface-process, junction, and snapshot/tooling regressions. scripts/ checks workbook aggregation invariants and previous-report selection. Run ctest --test-dir out/build/x64-Debug -C Debug --output-on-failure -j 4, and uv run --offline --with numpy --with pillow python -m unittest discover -s tests/scripts. These do not prove GUI rendering, historical world-save compatibility, full Earth benchmark skill, or high-resolution performance.

Tectonics alone: ctest --test-dir out/build/x64-Debug -C Debug -R "^PlateTectonicsTests$" --output-on-failure. Two imported historical golden tests explicitly skip obsolete baselines. The full-size deterministic replay with PNG artifacts is excluded from default CTest; run cmake-vs --build out/build/x64-Debug --config Release --target check-tectonics-slow explicitly. Artifacts stay inside the build tree. See docs/architecture/tectonic-contract-validation.md for module/tool commands and the native contract.
